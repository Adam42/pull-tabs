Pull Tabs
Empty your window in one pull.

Pull Tabs gathers every tab in the current window into one list and lets you act on the whole pile at once — save to a read-later service, bookmark, download, copy the URL, or close.

How it works

the whole idea
1
Pull
Every open tab drops into one list, all checked and set to your default action.
2
Set
Change the action for all tabs at once, or override any single row. Uncheck the ones you want to keep.
3
Go
One button runs the whole pile. With autoclose on, tabs clear themselves as each action lands.

No more Simple vs. Advanced modes — one list does both. Set everything at once when you want speed, or give individual tabs their own action when you don't. Same list, either way.
